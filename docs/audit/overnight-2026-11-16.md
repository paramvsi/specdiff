Touches every schema rule's location, so not done unsupervised. Severity of impact: medium (misleading path, no missed breaking change).

Options: (a) extend `request-property-became-required` to cover it (same severity, new message "required when `a` is sent"), (b) a new rule, (c) leave it (rare in OpenAPI).
