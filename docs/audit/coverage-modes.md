## DEFECTs (kept as `test.fail()`)

1. **MD-07: task-list checkboxes have no accessible name.** GFM `- [ ]` / `- [x]` render as `<input type="checkbox">` with no label, and axe reports `label: input`. This breaks CLAUDE.md rule 4 ("axe must be clean on every screen"). The test is `CM › MD-07 a rendered task list is axe clean`. The same violation first appeared in the MD-03 axe check while the test document still had a task list.
2. **OUT-11: the published schema is stale.** `apps/website/public/schema/report-v1.json`, copied to `dist/schema/`, is a hand copy, and nothing in the build regenerates it from `packages/core/src/report/schema.ts`. Compared with `specdiff schema`, it lacks the `"none"` version bump, change `tags` and the report-level `warnings`. Because the schema uses `additionalProperties: false`, a report that contains any of these fails the schema the website publishes. The test is `CM › OUT-11 the schema the website publishes is the one the CLI prints`.

## Not testable end to end here

- **IN-04, folder drop.** Playwright cannot dispatch a drop that carries a `FileSystemDirectoryEntry` (`webkitGetAsEntry`), and the file input is not `webkitdirectory`. Only the ZIP path is covered end to end.
- **TX-03, "50+ languages".** 5 grammars are checked end to end, not all 70.
- **OUT-11, live URL.** `https://specdiff.netlify.app/schema/report-v1.json` is not deployed, so only the built file is checked.
- **OUT-08, the print dialog itself.** The test checks the print CSS and a PDF render, not a browser print.

## Notes (not DEFECTs against docs/02)

- The OpenAPI summary reads "Where the 1 changes are" for one change (plural).
- The JSON "Markdown" export card says "A table of every change", but the file is a bulleted list.
- On Compare, "Detected" shows "Code" without the language. The language only appears on the result ("Code: Python").
- In the Workspace, a single `x-*` change is grouped as "Descriptions updated".
- For test authors: transforms and text options persist in IndexedDB between comparisons in one browser context. Sort runs before trim, so combining them can keep a difference; TX-09 uses one test per transform for this reason. Also, `page.route` answers skip CORS checks, so IN-03 uses a real local server without CORS headers.
