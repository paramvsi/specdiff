## Views and precision

Split or unified view. Precision is Smart, Word or Char. Ignore whitespace, case or line endings. Unchanged regions collapse, with controls to expand them. Move between changes with the overview ruler or the keyboard.

## Invisible characters

When a changed line differs only by characters you cannot see, they are named in the diff: `BOM`, `ZWSP`, `NBSP`, `SHY` and the bidirectional controls such as `RLO`. Hover a marker for its code point. Bidirectional controls are replaced by their names, so they cannot reorder the line you are reviewing (the Trojan Source attack). This applies in Text, JSON, YAML, code and the OpenAPI raw diff.

## Filters

Regex filters mask noise on both sides before comparing: timestamps, request IDs, UUIDs. Masked text shows as `‹name›`, with a hit count per filter.

```yaml title=".specdiff.yaml"
text:
  ignoreWhitespace: true
  precision: word
  filters:
    - { name: Timestamps, pattern: '\d{4}-\d{2}-\d{2}T[\d:.]+Z', replace: '‹time›' }
    - { name: Request IDs, pattern: 'req_[a-z0-9]{8,}', replace: '‹req-id›' }
```

## Transforms

Sort lines, lowercase, trim and normalise line breaks before comparing.

## Patches

Paste a unified patch or `git diff` output to open it as a text comparison. Moved blocks are detected, with edits inside them highlighted.
