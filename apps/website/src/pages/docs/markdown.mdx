## Rendered diff

Insertions and deletions are highlighted word by word in the rendered document. Switch between rendered, source and side-by-side views.

## Outline

Headings are listed with added, removed or edited marks. Select one to jump to it.

## Links, images and code

Changed links and images show the before and after. Changed code blocks are shown as line diffs.

## Broken anchors

When a heading is renamed, Specdiff checks whether anything still links to the old anchor, and tells you where.

GitHub-flavoured Markdown is supported: tables, task lists and callouts. Rendered Markdown is sanitised.
