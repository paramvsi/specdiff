## Try it with a sample

Open the app with [a sample comparison](/app/?sample=openapi) loaded: two versions of a payments API with breaking, safe and docs-only changes, and a suggested next version.

## Compare your own files

1. Open [the app](/app/).
2. Add the older version on the left and the newer one on the right: paste, drop a file, pick one, or load a URL.
3. Specdiff detects the mode (OpenAPI, JSON, YAML, Markdown, code or text). Change it from the mode menu if it guesses wrong.
4. Read the summary, step through the changes, and copy the changelog.

<Callout>No account, no upload. Files are parsed and compared in background workers in this tab. See [Privacy](/docs/privacy/).</Callout>

## From a terminal

```bash
npx specdiff-cli old.yaml new.yaml
```

This opens the same app on your machine with both files loaded. Add `--ci` to print the report and exit non-zero instead; see [CLI](/docs/cli/).
