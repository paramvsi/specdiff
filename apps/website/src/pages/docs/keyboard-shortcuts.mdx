## Move around

| Action | Keys |
|---|---|
| Next change | <kbd>J</kbd> |
| Previous change | <kbd>K</kbd> |
| Next to review | <kbd>N</kbd> |
| Go to line | <kbd>⌘</kbd> <kbd>G</kbd> |
| Open command palette | <kbd>⌘</kbd> <kbd>K</kbd> |

## Review

| Action | Keys |
|---|---|
| Accept change | <kbd>A</kbd> |
| Reject change | <kbd>R</kbd> |
| Mark as viewed | <kbd>V</kbd> |
| Explain this change | <kbd>E</kbd> |
| Copy link to change | <kbd>⇧</kbd> <kbd>C</kbd> |

## View

| Action | Keys |
|---|---|
| Split / unified | <kbd>⇧</kbd> <kbd>U</kbd> |
| Word wrap | <kbd>⌥</kbd> <kbd>Z</kbd> |
| Show unchanged lines | <kbd>⇧</kbd> <kbd>E</kbd> |
| Summary · Workspace · Raw | <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> |
| Toggle filters | <kbd>F</kbd> |

## Files

| Action | Keys |
|---|---|
| Swap before and after | <kbd>⇧</kbd> <kbd>S</kbd> |
| Open file | <kbd>⌘</kbd> <kbd>O</kbd> |
| Load from URL | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>O</kbd> |
| Share | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>S</kbd> |
| Show this sheet | <kbd>?</kbd> |

On Windows and Linux, use <kbd>Ctrl</kbd> for <kbd>⌘</kbd>.
