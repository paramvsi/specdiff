## Changelog

Pick a template: release notes, Keep a Changelog, a PR comment or a Slack message. Group by severity, include or leave out docs-only changes, then edit the text before you copy or download it.

## Reports

- **Markdown**, for PRs and wikis.
- **JSON**, with a published JSON Schema, for your own tooling.
- **Standalone HTML**, one file you can attach or archive. It also prints cleanly.

The same two inputs and options always give a byte-identical report.

## RSS

The changelog can also be produced as an Atom feed for static hosting (`changelogFeed` in `@specdiff/core`).

## Copy for LLM

Copy the breaking changes, all changes or the current change as text for an assistant of your choice. Specdiff makes no AI calls.
