## With the pre-commit framework

```yaml title=".pre-commit-config.yaml"
repos:
  - repo: local
    hooks:
      - id: specdiff
        name: specdiff
        entry: npx specdiff-cli --ci --fail-on breaking HEAD:openapi.yaml openapi.yaml
        language: system
        pass_filenames: false
        files: openapi\.yaml$
```

`HEAD:openapi.yaml` is the last committed version; `openapi.yaml` is the file in your working copy (not only the staged part).

You can also leave out the paths and `pass_filenames: false`, so pre-commit passes the matching file. This works when `files` matches a single file. Given one file, the CLI compares `HEAD:<file>` with the working copy, and a file that is not in `HEAD` yet passes. With two arguments, a file missing from `HEAD` is an input error (exit code 2).

```yaml
        entry: npx specdiff-cli --ci --fail-on breaking
        files: openapi\.yaml$
```

## Without a framework

```sh title=".git/hooks/pre-commit"
#!/bin/sh
git diff --cached --quiet -- openapi.yaml && exit 0
exec npx specdiff-cli HEAD:openapi.yaml openapi.yaml --ci --fail-on breaking
```

Make it executable with `chmod +x .git/hooks/pre-commit`.

<Callout>The hook reads `.specdiff.yaml` and `.specdiff/decisions.json`. Accept a breaking change in the app, commit the decision, and the hook lets it through.</Callout>
