## With the pre-commit framework

```yaml title=".pre-commit-config.yaml"
repos:
  - repo: local
    hooks:
      - id: specdiff
        name: specdiff
        entry: npx specdiff-cli pre-commit --fail-on breaking
        language: system
        files: openapi\.yaml$
```

pre-commit passes every matching file in one call. For each one, `specdiff-cli pre-commit` compares the last committed version (`HEAD:<file>`) with the file in your working copy (not only the staged part). A file that is not in `HEAD` yet is new, so it passes. Leave `pass_filenames` at its default: the hook needs the file names.

Once `specdiff-cli` is published, you can use this repository as a hook repository instead of a local hook. It ships a `.pre-commit-hooks.yaml` with the hook id `specdiff`:

```yaml title=".pre-commit-config.yaml"
repos:
  - repo: https://github.com/paramvsi/specdiff
    rev: v1.0.0
    hooks:
      - id: specdiff
        files: openapi\.yaml$
```

## Without a framework

```sh title=".git/hooks/pre-commit"
#!/bin/sh
git diff --cached --quiet -- openapi.yaml && exit 0
exec npx specdiff-cli HEAD:openapi.yaml openapi.yaml --ci --fail-on breaking
```

Make it executable with `chmod +x .git/hooks/pre-commit`.

<Callout>The hook reads `.specdiff.yaml` and `.specdiff/decisions.json`. Accept a breaking change in the app, commit the decision, and the hook lets it through.</Callout>
