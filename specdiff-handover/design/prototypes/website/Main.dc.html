Know what your API change breaks before you ship it.

Specdiff compares two versions of an OpenAPI spec, a JSON or YAML file, a Markdown doc or source code. It tells you which changes break clients, why, and how to avoid it, then writes the changelog.

Try it with a sampleCompare my files
$ npx specdiff old.yaml new.yaml
Runs in your browser. Nothing is uploaded.

From two files to a release decision

  1. 1

    Drop in two versions

    Paste, drop files or a folder, or load a URL. Specdiff detects the format and resolves every $ref, including across files.

    payments-v1.yamlBefore
    payments-v2.yamlAfter
    or paste a GitHub linkURL
  2. 2

    See what it means

    Changes are grouped by endpoint and ranked by severity. Each one says who it breaks and how to avoid it. A shared schema change is shown once, not twenty times.

    DELETEEndpoint removed
    POSTcurrency is now required
    GETlimit maximum lowered
    POSTEndpoint added
  3. 3

    Ship with a changelog

    Get the suggested version bump and a changelog in your format: release notes, Keep a Changelog, a PR comment or a Slack message.

    CHANGELOG.md
    ## 2.0.0

### Breaking
- `POST /v1/payments` now requires
  `currency`.
- `DELETE /v1/refunds/{id}` removed.

### Added
- `POST /v1/payouts`.

A line diff shows text. Specdiff shows meaning.

Key order, formatting and moved blocks don’t show up as changes. Renamed path parameters aren’t removals. Swagger 2.0 compares cleanly against OpenAPI 3.1.

API docs that remember every version

The Specdiff Viewer is an interactive API reference, with search, code samples and Try it. It also knows your API’s history, so consumers see what’s new, changed or about to go away.

  • A timeline of versions

    Load several releases of a spec and switch between them. Every endpoint shows when it was added, changed or deprecated.

  • What changed for me?

    Pick the endpoints your app calls, or drop a HAR file of real traffic. Everything else fades away.

  • Try it, with a warning

    Send real requests from the page. If a request would fail on the newer version, you’ll know before you upgrade.

  • Drop-in, like Swagger UI

    Serve it from Spring Boot at /specdiff, Express or Fastify at /docs, a React component or a single script tag.

Your spec never leaves the tab.

Internal APIs, unreleased endpoints and customer configs are safe to paste here. Open the network panel and check.

  • Parsed in your browserBoth files are read and compared in background workers in this tab. There is no server to send them to.
  • Links carry the filesA share link holds the compressed files after the #, which browsers never send to a server.
  • Lock links with a passphraseOptional AES-GCM encryption in the browser. Without the passphrase, the link is unreadable.
  • No accounts, no content analyticsHistory stays in this browser’s storage. Clear it with one click.

Use it where you already work

The same engine runs in the web app, your terminal, any CI and your own service. One .specdiff.yaml configures all of them.

CLI

Open the local UI, or fail CI on breaking changes.

$ npx specdiff old.yaml new.yaml
$ npx specdiff main:openapi.yaml openapi.yaml \
    --ci --fail-on breaking

Pre-commit hook

Catch breaking changes before you push. Works with any CI too.

repos:
  - repo: local
    hooks:
      - id: specdiff
        entry: npx specdiff --ci HEAD:openapi.yaml openapi.yaml
        language: system

Spring Boot

Serve the Viewer at /specdiff from your app’s own OpenAPI document.

<dependency>
  <groupId>io.github.paramvsi</groupId>
  <artifactId>specdiff-spring-boot-starter</artifactId>
</dependency>

React

Embed the Viewer or a diff in any React app.

import { SpecdiffViewer } from '@specdiff/react'

<SpecdiffViewer url="/openapi.json"
  compareWith="/openapi-1.5.json" />

Express and Fastify

Mount the Viewer at /docs in two lines.

import { specdiff } from '@specdiff/express'

app.use('/docs', specdiff({ spec: './openapi.yaml' }))

Script tag

No build step. Works on any page.

<script src="…/@specdiff/embed"></script>
<script>
  Specdiff.mount(el, { url: '/openapi.json' })
</script>
