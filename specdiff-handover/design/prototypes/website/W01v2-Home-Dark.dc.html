Questions

Is it really free?

Yes. Specdiff is open source under the MIT licence. There are no accounts, plans or paid tiers.

Are my files uploaded anywhere?

No. Files are read and compared in your browser. Share links carry the files after the #, which browsers never send to a server, and you can lock them with a passphrase.

How large can a spec be?

A 10 MB spec stays responsive. Above 25 MB, Specdiff offers a text-only comparison. The CLI handles larger files.

Can I run it in CI?

Yes. npx specdiff --ci works in any CI: it prints the changelog and exits non-zero on breaking changes. A pre-commit hook catches them before you push.

Which formats does it support?

Swagger 2.0 and OpenAPI 3.0, 3.1 and 3.2, JSON, YAML, Markdown and plain text. Code mode covers TypeScript, JavaScript, Java and Python, in Beta.
