POST/v1/paymentsBreaking

Create a payment

Charges a card or bank account. The payment is created in pending and moves to succeeded or failed. Send an Idempotency-Key header so retries never charge twice.

DocsHistory 4
Changed since 1.5.0!Breakingcurrency is now required. Requests without it get 400.+Safecurrency must be a three-letter ISO 4217 code.

Headers

  • Idempotency-KeystringoptionalA unique value you generate. Retries with the same key return the first result.

Request body

application/json
  • amountintegerrequiredAmount in the smallest currency unit, for example 1050 for 10.50 EUR. Minimum 50.
  • currencystringrequiredChangedThree-letter ISO 4217 code, upper case.Pattern ^[A-Z]{3}$ · was optional before 2.0.0
  • sourcestringrequiredID of a saved card or bank account, starting with src_.
  • descriptionstringoptionalShown on the customer’s receipt. Up to 255 characters.
  • metadataobjectoptionalUp to 20 key-value pairs for your own reference.

Responses

  • 201Payment created. Returns the Payment object.
  • 400Invalid request, for example a missing currency.
  • 402The card was declined.
  • 409An idempotency key was reused with a different body.

  {"amount":1050,"currency":"EUR",
