Payments API
POST/v1/paymentsBreaking

Create a payment

Charges a card or bank account. Send an Idempotency-Key so retries never charge twice.

!Breakingcurrency is now required since 2.0.0.

Request body

  • amountintegerrequiredAmount in the smallest currency unit.
  • currencystringrequiredChangedThree-letter ISO 4217 code.
  • sourcestringrequiredID of a saved card or bank account.
curl https://api.acme.dev/v1/payments \
  -H "Authorization: Bearer …" \
  -d amount=1050 \
  -d currency=EUR
